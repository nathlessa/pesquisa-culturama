# Pesquisa Culturama

Formulário de pesquisa de opinião desenvolvido com HTML e CSS.

## Tecnologias

* HTML5
* CSS3

## Funcionalidades

* Formulário de pesquisa de opinião
* Validação nativa dos campos
* Upload de imagem
* Seleção de opções por rádio e checkbox
* Lista de opções com `datalist`
* Validação de telefone com `pattern`
* Página de sucesso após o envio

## Acessibilidade

* Uso de elementos HTML semânticos
* Associação entre `label` e campos do formulário
* Uso de `aria-label` e `aria-describedby`
* Textos de apoio para orientar o preenchimento dos campos

## Estrutura

```text
pesquisa-culturama/
├── index.html
├── sucesso.html
├── css/
│   └── style.css
└── img/
    └── logo-culturama.png
```

## Objetivo

Projeto desenvolvido para praticar a criação e estilização de formulários com HTML e CSS, incluindo validação de campos e boas práticas de acessibilidade.

Visualize o projeto aqui: https://nathlessa.github.io/pesquisa-culturama/
